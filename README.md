# Inventory_System
I developed a full-stack Inventory Analytics System for Vermin Industries using Python, Streamlit, MySQL, and Power BI — replacing their manual Excel-based process with a centralised, data-driven platform.

Data Collection & Database Design

Collected real inventory data covering 120 purchase orders, 17 components, and 12 suppliers
Designed and implemented a normalised MySQL database with 4 relational tables and 3 foreign key relationships

2. Streamlit Web Application
   
Built a full-stack web application using Python and Streamlit 
Implemented complete CRUD operations — Add, Edit, Delete records across all 4 data tables
Developed a live SQL query runner using in-memory SQLite with CSV export

4. Power BI Dashboard

Designed a 7-page interactive Power BI dashboard with 22 custom DAX measures
Covered Inventory Overview, Purchase Order Analysis, Supplier Intelligence, Stock Monitoring, Reorder Alerts, India vs Korea Comparison, and Executive Summary

4. Data Analysis & Insights
   
Identified 94.17% delivery rate (113 out of 120 orders delivered)
Flagged 42 critical stock items requiring immediate procurement action
Discovered Korea suppliers outperform India — rating 4.28 vs 4.11, 2 days faster delivery
Computed an Overall Inventory Health Score of 84%

6. Documentation
   
Prepared complete project report following Parul University MCA guidelines including DFDs, ERD, Use Case Diagram, Class Diagram, Test Cases, and Future Enhancements
